# Mini-IDS: Dataset Acquisition & Management Guide

## 1. Benchmark Datasets Overview

Mini-IDS supports two primary industry-standard intrusion detection benchmarks:

### 1.1 CICIDS2017 (Primary Benchmark)
- **Publisher:** Canadian Institute for Cybersecurity (UNB)
- **Official Documentation:** [https://www.unb.ca/cic/datasets/ids-2017.html](https://www.unb.ca/cic/datasets/ids-2017.html)
- **Description:** Generated over 5 consecutive days of benign user behavior and 14 modern attack profiles. Features represent bidirectional network flow statistics generated by the CICFlowMeter tool.
- **Attack Classes:** PortScan, DoS/DDoS (Slowloris, Hulk, GoldenEye), Brute Force (SSH, FTP), Botnet, Infiltration, Web Attacks.
- **Access Protocol:** Direct downloads from UNB portals frequently require institutional registration forms or gated credentials. Mini-IDS implements automated discovery with mirror fallback and manual offline ingestion instructions.

### 1.2 UNSW-NB15 (Secondary Benchmark)
- **Publisher:** Cyber Range Lab of UNSW Canberra
- **Official Documentation:** [https://research.unsw.edu.au/projects/unsw-nb15-dataset](https://research.unsw.edu.au/projects/unsw-nb15-dataset)
- **Description:** Real modern normal activities and synthetic contemporary attack behaviors captured using IXIA PerfectStorm.
- **Attack Classes:** Fuzzers, Analysis, Backdoors, DoS, Exploits, Generic, Reconnaissance, Shellcode, Worms.

## 2. Dataset Directory Structure

Dataset assets are partitioned into isolated directories tracked under `data/datasets/`:

```text
data/datasets/
├── cicids2017/
│   ├── raw/                  # Downloaded or user-provided raw CSV archives
│   │   └── cicids2017_sample_1200.csv
│   ├── processed/            # Cleaned, standardized tabular splits
│   │   ├── train.csv
│   │   ├── val.csv
│   │   └── test.csv
│   └── metadata/             # Provenance manifests (*.manifest.json)
└── unsw_nb15/
    ├── raw/
    ├── processed/
    └── metadata/
```

> [!NOTE]
> `.gitignore` explicitly excludes large raw data archives (`*.csv`, `*.zip`) while preserving `.gitkeep` and `metadata/*.manifest.json` so dataset provenance remains committed to source control.

## 3. Cryptographic Verification & Manifests

Every acquired dataset is indexed with a JSON provenance manifest containing:
- `dataset_name`: Name of the source benchmark.
- `original_source`: URI or mirror endpoint.
- `retrieval_timestamp`: Epoch timestamp of acquisition.
- `file_name`: Basename of the file.
- `file_size_bytes`: Byte length.
- `sha256_checksum`: Cryptographic SHA-256 hash.
- `verification_status`: `VERIFIED`, `UNVERIFIED`, or `FAILED`.
- `doc_reference`: Link to research paper or benchmark documentation.

Example manifest (`data/datasets/cicids2017/metadata/cicids2017_sample_1200.csv.manifest.json`):
```json
{
  "dataset_name": "CICIDS2017",
  "original_source": "synthetic_fixture://cicids2017_sample_1200",
  "retrieval_timestamp": 1770000000.0,
  "file_name": "cicids2017_sample_1200.csv",
  "file_size_bytes": 312450,
  "sha256_checksum": "a8f3b...",
  "verification_status": "VERIFIED",
  "doc_reference": "https://www.unb.ca/cic/datasets/ids-2017.html",
  "processing_status": "RAW"
}
```

## 4. Automation Commands

### 4.1 Discover & Inspect Datasets
```powershell
python scripts/inspect_datasets.py
```
Outputs the status of local dataset directories, discovered files, row counts, and manifests.

### 4.2 Download Datasets
```powershell
# Attempt automated download from mirror archives
python scripts/download_datasets.py --dataset cicids2017
python scripts/download_datasets.py --dataset unsw_nb15

# If remote portals are gated or firewalled, generate the deterministic sample fixture:
python scripts/download_datasets.py --sample
```

### 4.3 Clean & Preprocess
```powershell
python scripts/preprocess_datasets.py --dataset cicids2017 --split stratified --test-size 0.20
```

## 5. Offline Manual Acquisition

If automated downloads fail due to network restrictions or university portal changes:
1. Visit [UNB CICIDS2017 Downloads](https://www.unb.ca/cic/datasets/ids-2017.html) in your browser.
2. Download any of the generated labeled flow CSVs (e.g. `Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv`).
3. Place the file into `data/datasets/cicids2017/raw/`.
4. Run `python scripts/inspect_datasets.py` to verify discovery.
